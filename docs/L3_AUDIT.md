# F37 L3 Gold Standard Audit

F37 is eligible for L3 only when the promotion commit demonstrates all of the following:

- six distinct evaluation roles with explicit planning, quality, safety, robustness, calibration, and adjudication responsibilities
- normalized weighted rubrics and bounded 0 to 1 score contracts
- shared traceable evaluation state with evidence, risks, disagreements, and chronological trace
- fail-closed minimum score, safety, disagreement, robustness, calibration, and missing-candidate behavior
- human review that cannot override failed safety or score criteria
- unit, integration, adversarial, and malformed-input tests
- primary deterministic benchmark scenarios
- separate eight-scenario held-out reproducibility suite with 100 percent expected-behavior pass rate
- minimal and complete clean-checkout examples
- Python 3.10, 3.11, and 3.12 CI green for lint, tests, primary benchmarks, held-out suite, examples, and smoke run
- Python 3.12 held-out artifact publication
- version 1.0.0, MIT license, citation metadata, contribution/security/changelog documentation

L3 is a reference-quality engineering maturity designation. It is not a guarantee that the evaluator is universally correct, unbiased, policy-complete, or sufficient as the sole authority for consequential model deployment decisions.
