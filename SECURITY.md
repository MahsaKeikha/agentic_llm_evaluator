# Security Policy

Please report security-sensitive issues privately through GitHub's security reporting mechanisms when available rather than posting exploit details in a public issue.

Security concerns include prompt or rubric injection that changes evaluator authority, unsafe judge bypasses, data leakage, provenance tampering, score manipulation, dependency vulnerabilities, and approval-gate bypasses.

This repository is a reference implementation, not a certification service. Production deployments require independent security review and domain-specific validation.
